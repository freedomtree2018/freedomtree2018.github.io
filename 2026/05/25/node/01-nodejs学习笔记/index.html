Node.js学习指南-基础知识

Posted on 2026-05-25 Edited on 2026-05-29

1. Node.js 简介

1.1 什么是 Node.js

Node.js 是一个基于 Chrome V8 引擎构建的 JavaScript 运行环境，它让 JavaScript 不再局限于浏览器，而可以在服务器端、命令行、桌面应用等环境中运行。

  • Node.js 提供了文件系统、网络、进程等底层能力。
  • 它不是框架，而是一个运行时环境。
  • Node.js 中没有浏览器的 DOM、BOM 和窗口对象。

官网地址：https://nodejs.org/zh-cn/

1.2 Node.js 的应用场景

Node.js 的生态非常丰富，常见的应用场景包括：

  • 构建 Web 服务、RESTful API
  • 开发命令行工具和自动化脚本
  • 使用 Electron 构建跨平台桌面应用
  • 使用 Socket 实现实时通信
  • 处理文件、流和后台任务

一些常见框架：

  • Express：轻量级 Web 框架
  • Koa：更现代的中间件框架
  • NestJS：结构化的企业级后端框架
  • Electron：桌面应用开发

1.3 为什么学习 Node.js

对于熟悉前端的开发者来说，学习 Node.js 有以下优势：

  • 同一种语言（JavaScript）实现前端和后端开发
  • 可以快速上手后端基本能力
  • npm 生态提供大量实用包
  • 能够扩展为全栈开发能力

1.4 node.js的学习路径

javascript基础语法+ Node.js内置模块（fs,path,http等）+ 第三方API模块（express/msSql等）

5.http模块

5.1 什么是 http 模块

基础概念回顾

  • 客户端：网络节点中，负责消费资源的电脑 / 设备。
  • 服务器：网络节点中，负责对外提供网络资源的电脑 / 设备。

http 模块定义

  • http 模块是 Node.js 官方内置的、用于创建 Web 服务器的核心模块。
  • 通过 http.createServer() 方法，可快速将普通电脑变为 Web 服务器，对外提供 Web 资源服务。

模块导入方式

5.2 http 模块的作用与优势

传统 Web 服务器实现方式
普通电脑需安装 IIS、Apache 等第三方 Web 服务器软件，才能对外提供 Web 服务。

Node.js 中的实现方式
无需依赖 IIS、Apache 等第三方软件，仅通过 Node.js 内置的 http 模块，编写少量代码即可手写一个服务器软件，对外提供 Web 服务。

5.3 服务器相关核心概念

5.3.1 IP 地址

定义：互联网中每台计算机的唯一标识地址，具有唯一性，类比现实中的 “电话号码”。
格式：采用点分十进制表示，形式为 a.b.c.d，其中 a/b/c/d 均为 0~255 之间的整数，例如 192.168.1.1。
关键说明：

  • 所有公网 Web 服务器都有独立 IP 地址，可通过 ping 域名 命令查看（如 ping www.baidu.com）。
  • 开发测试阶段，可使用 127.0.0.1 访问本地电脑上的服务，此时电脑既是客户端也是服务器。

5.3.2 域名与域名服务器（DNS）

域名：IP 地址的字符化别名，解决 IP 地址不直观、难记忆的问题（如 www.baidu.com 对应百度服务器 IP）。
DNS（域名服务器）：存储 IP 地址与域名的一一对应关系，负责将域名解析为 IP 地址，让用户可通过域名访问服务器。
关键说明：

  • 仅使用 IP 地址也可正常访问服务器，域名仅为提升易用性。
  • 开发测试阶段，127.0.0.1 与 localhost 等价，均指向本地电脑，无使用区别。

5.3.3 端口号

作用：一台电脑可同时运行多个 Web 服务，端口号用于区分不同服务，类比现实中的 “门牌号”，让请求能精准交付给对应服务处理。

关键说明：

  • 同一端口号不能同时被多个 Web 服务占用。
  • HTTP 协议默认端口为 80，HTTPS 为 443，URL 中可省略 80 端口（如 http://example.com 等价于 http://example.com:80）。
